# CommLocker v2

The redesigned CommLocker phone app, as a clickable mockup, with the documents a developer needs to build it.

- `index.html` — the mockup. Open it in any browser or on a phone; deploy this folder as-is to Netlify.
- `HANDOFF.md` — the developer spec: screens, data model, hashing, acceptance checklist.
- `DEVELOPER-BRIEF.md` — one page for the development team: what stays, what changes, three iterations.
- `PLAN.md` — the plan in plain words, with flowcharts.
- `walkthrough.html` + `shots/` — screen-by-screen walkthrough with captures of the tour.
- `before-after.svg` — today versus the redesign.
- `wordmark.png` — the CommLocker wordmark used in the header.
